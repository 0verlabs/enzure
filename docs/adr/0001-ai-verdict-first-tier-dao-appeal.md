# AI Verdict is the first tier of resolution, with DAO Appeal as the final one

Disputed Assertions get a first ruling from a NEAR AI Cloud model running in a TEE, which the NEAR contract checks on-chain against a Registered Key. The party that loses the AI Verdict can Appeal to a Sputnik DAO, whose decision is final; Conflicting Verdicts and UNRESOLVABLE go to Appeal automatically. We rejected a token vote like UMA's DVM because it takes days per dispute and has been swayed by large holders (Polymarket disputes in 2025). We rejected making the AI Verdict final because a TEE signature proves which model produced which output, not that the output is correct, and anyone can rerun a prompt until they get the verdict they want.
