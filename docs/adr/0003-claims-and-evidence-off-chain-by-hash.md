# Claims and Evidence are stored off-chain and committed on-chain by hash

The contract stores only the sha256 hash of each Claim and piece of Evidence, so Claims have no on-chain size limit and undisputed Assertions never put their text on-chain. The content lives in a hash-addressed store (Cloudflare R2 behind a Worker) that rejects any upload whose bytes don't match the hash, so anyone can mirror it and nobody can swap it. When an AI Verdict is submitted, the submitter includes the original bytes; the contract checks them against the stored hashes and builds the AI prompt from them, so the signed verdict is provably about this Assertion. The practical size limit is therefore the model's context window and NEAR's 1.5 MiB transaction size. If content is withheld or too large and no AI Verdict arrives within a set time after the dispute, the Assertion goes to Appeal. Content is public and unencrypted, because Disputers and the DAO must be able to read it. We rejected on-chain text (size limit, storage cost) and IPFS (pinning and gateways for little gain in this version).
