Enzure is an optimistic oracle for the promises a contract can't check by itself, like "I delivered the work in this brief". You post a statement with a bond. If nobody disputes it in time, it settles as true. If someone does, an AI Verdict rules on it, and the losing side can appeal to a DAO.

<Note>
Enzure runs on NEAR testnet. It is not on mainnet yet.
</Note>

## Features

- **Bonded statements.** Post a statement with a bond. If nobody disputes it in time, it settles as true.
- **Verified AI Verdict.** A NEAR AI model in a TEE rules on each dispute, and the contract checks the model's signature itself.
- **DAO appeals.** The losing side can appeal the AI Verdict. A DAO makes the final ruling.
- **Cross-chain settlement.** Outcomes reach contracts on NEAR, or EVM chains through Chain Signatures, with no bridge.
- **No operator needed.** Anyone can settle, submit a verdict or deliver a result, so nothing waits on one service.
